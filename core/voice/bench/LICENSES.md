# In-app benchmark set v2: licenses and credits

The 14 clips here are copied unchanged from the Silas bench set (`bench/`, release `bench-set-v1`). Each
clip's license is in its `license` field in `manifest.json`. The full credits are in `bench/LICENSES.md`.
